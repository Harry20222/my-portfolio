# Harry Bosco Denis — Personal Developer Portfolio

A modern, responsive, dark-themed personal portfolio built with Next.js (App Router), Tailwind CSS, and Framer Motion.

## Features
- **Centralized Data Store (`src/data/portfolioData.ts`)**: Update projects, skills, and bio in one place.
- **Co-op Availability Banner**: Highlights Spring 2027 Co-op availability.
- **Projects Showcase**: Interactive cards for Billify, Byte2Beat, Educational Shorts Platform, and ParkPulse.
- **Activities & Leadership**: Timeline view of AAEIO Secretary role, Bearcat Coders TA, and Baker College volunteer work.
- **Serverless Contact Form**: Integrated with Formspree for direct email notifications.

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

3. **Deploy to Vercel:**
   Push to GitHub and connect the repository on [Vercel](https://vercel.com).
